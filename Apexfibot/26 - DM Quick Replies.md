## 🔥 คำถามทางเทคนิค

### Q: "บอทหายไปไหน? ไม่ตอบ"
```
ลองทำตามนี้ครับ:

1. กด /start ใหม่
2. ถ้ายังไม่ตอบ → restart Telegram (ปิด-เปิด app)
3. ถ้ายังไม่ตอบ → ลบบอทออก แล้วเข้าใหม่ที่ t.me/Apexify_Trading_Bot
4. ถ้ายังไม่ได้ → ทักหา admin: @YourTGHandle

ตอนนี้บอทเปิด 24/7 ครับ ไม่น่าล่ม — ส่วนใหญ่ปัญหาอยู่ที่แอป Telegram เอง
```

### Q: "ส่งสลิปแล้วยังไม่ upgrade"
```
ลองเช็คตามนี้ครับ:

1. รอ 30 วินาที — AI ใช้เวลา process
2. ตรวจว่ายอดที่โอน = 79 (VIP) หรือ 109 (PRO)
3. ตรวจว่าเลขบัญชีถูก: 135-1-34469-1 กสิกร
4. ลองส่งสลิปอีกครั้ง (ภาพชัด — เห็นยอด + วันที่)

ถ้ายังไม่ขึ้น → ทักหา admin พร้อมส่งสลิปใหม่ + เลขบัญชีของคุณ
admin จะเช็คให้ใน 1-2 ชม.
```

### Q: "พิมพ์หุ้นแล้วไม่เจอ"
```
ลองเช็คชื่อ ticker ครับ:

✅ ถูก: AAPL (ไม่มี space, ไม่มี $)
❌ ผิด: $AAPL, "AAPL", aapl

ถ้าเป็นหุ้นไทย:
✅ PTT.BK หรือ PTT
❌ ปตท, PTT (ไม่ตรง spelling)

หา ticker ที่ถูกต้องได้ที่ Yahoo Finance:
finance.yahoo.com → search ชื่อบริษัท → ดู symbol
```
