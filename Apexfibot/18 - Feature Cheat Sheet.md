**ใช้ไม่ได้ (ต้องสร้างระบบเพิ่ม):**
- ❌ ส่วนลด % ราคา ("30% off")

## 💡 Power Phrases (ใช้ปิดการขาย)

ลำดับที่แนะนำ:

1. **เปิด:** "ลองฟรี 7 วันก่อนเลยครับ ไม่ต้องโอนอะไร"
2. **สร้างความน่าเชื่อ:** "พิมพ์ /track ดูสถิติได้เลยครับ มี XX% hit rate"
3. **ปิด ratio low-effort:** "วันละ 2-3 บาท คุ้มกว่ากาแฟแน่นอน"
4. **ลดความเสี่ยง:** "ไม่ผูกบัตร ยกเลิกได้ตลอด"
5. **กระตุ้นเร่ง:** "ลอง /freetrial ตอนนี้เลยไหมครับ ผมจะรอดูว่ามีอะไรไม่เข้าใจ"

## 🎯 Sales Funnel Stages

### Stage 1: Awareness (รู้จัก)
- ส่ง bot link + แนะนำ /demo
- กระตุ้น: "ลองพิมพ์ AAPL ดูเลยฟรี"

### Stage 2: Trial (ลองใช้)
- เน้น `/freetrial` 7 วัน
- Coach การใช้งาน — ตอบคำถาม

### Stage 3: Engagement (ใช้สม่ำเสมอ)
- Daily streak system → habit
- Watchlist + alerts → return

### Stage 4: Conversion (สมัคร)
- ก่อน trial หมด 1-2 วัน → ทักไป
- บอก benefit ที่จะหายไป (chart, plan, alerts)

### Stage 5: Retention (ต่ออายุ)
- 7/3/1 วันก่อนหมด → renewal reminder อัตโนมัติ
- เน้น "ใช้งานต่อเนื่อง — ไม่เสียวันที่เหลือ"

### Stage 6: Advocacy (บอกต่อ)
- Referral system → win-win
- เก็บ testimonial
