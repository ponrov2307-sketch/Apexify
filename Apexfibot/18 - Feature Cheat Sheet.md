- **Apexify: ขอเมื่อไรก็ได้ + Track Record โปร่งใส**

- **Apexify: yfinance live + cron alerts**

## ⚡ ข้อดีจุดขายลับ (พูดถึงตอนปิด)

## 🎁 Promo Strategy ปัจจุบัน (จำให้ขึ้นใจ)

> **ตอนนี้ "แจก" ไม่ใช่ "ลดราคา"**

| ช่องทาง | สิ่งที่แจก | ใครได้ | เงื่อนไข |
|--------|----------|------|---------|
| Free Trial | PRO 7 วัน | คนใหม่ | พิมพ์ `/freetrial` (1 ครั้ง/บัญชี) |
| Referral (เพื่อน) | VIP 3 วัน | เพื่อน | สมัครผ่านลิงก์ |
| Referral (คุณ) | +3 quota / +10 วัน | คนชวน | ทุก 1/3 คน |
| Daily Streak | +1 วัน VIP | ทุกคน | ใช้ครบ 7 วันต่อเนื่อง |
| **Promo Code** | **+N วัน VIP/PRO** | **ใครก็ตามที่มีโค้ด** | **`/redeem CODE`** |

### 💡 เกี่ยวกับ Promo Code (ใช้ได้แล้วแบบ "แจกของฟรี")

**ใช้ได้:** สร้างโค้ด → user ใส่ → ได้วัน VIP/PRO ฟรี
- Admin: `/gencode 7 100 vip` (7 วัน, 100 uses, role=vip) → ระบบ gen `VIP7-A1B2C3` ให้
- User: `/redeem VIP7-A1B2C3` → ได้ VIP +7 วัน

**ใช้ไม่ได้ (ต้องสร้างระบบเพิ่ม):**
- ❌ ส่วนลด % ราคา ("30% off")
- ❌ ลดยอดสลิป
- ❌ Conditional discount (ลดถ้าซื้อปี vs เดือน)
→ ระบบ payment ต้องเขียนเพิ่ม 3 ส่วน: pricing display, slip verification, code-binding

**Sales angle:** "ลองฟรีก่อน, ชอบค่อยสมัคร" — ไม่กดดัน

## 🎯 Sales Funnel Stages

### Stage 1: Awareness (รู้จัก)
- ส่ง bot link + แนะนำ /demo
- กระตุ้น: "ลองพิมพ์ AAPL ดูเลยฟรี"

### Stage 2: Trial (ลองใช้)
- เน้น `/freetrial` 7 วัน
- Coach การใช้งาน — ตอบคำถาม

### Stage 3: Engagement (ใช้สม่ำเสมอ)
- Daily streak system → habit
- Watchlist + alerts → return

### Stage 4: Conversion (สมัคร)
- ก่อน trial หมด 1-2 วัน → ทักไป
- บอก benefit ที่จะหายไป (chart, plan, alerts)

### Stage 5: Retention (ต่ออายุ)
- 7/3/1 วันก่อนหมด → renewal reminder อัตโนมัติ
- เน้น "ใช้งานต่อเนื่อง — ไม่เสียวันที่เหลือ"

### Stage 6: Advocacy (บอกต่อ)
- Referral system → win-win
- เก็บ testimonial
