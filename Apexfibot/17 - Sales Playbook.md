## 🧠 Mental Framework (3 ค่าหลัก — จำแค่นี้พอ!)

### 1️⃣ "AI อ่านกราฟแทนคุณ" 🤖
- Trend Radar 3 ระยะ (วัน / สัปดาห์ / เดือน)
- Conviction Score 0-100 (มั่นใจแค่ไหน)
- AI Insight (สรุป actionable)

→ **เปรียบ:** แทนนักวิเคราะห์เทคนิคส่วนตัวที่ทำงาน 24/7

### 2️⃣ "แผนเทรดสำเร็จรูป" 🎯 (จุดขาย PRO!)
- Entry zone + TP1 + TP2 + SL พร้อม %
- กราฟวาด zone ให้ดูทันที
- เงื่อนไขยืนยัน + ยกเลิก Plan
- R:R Analysis + Position Sizing tip

→ **เปรียบ:** เปิดบอทดูก็รู้เลยว่าจะซื้อตรงไหน ขายเมื่อไร

### 3️⃣ "ติดตามอัตโนมัติ 24/7" 🔔
- Smart Alerts (RSI, MACD, Whale, News)
- Custom Price Alerts
- Morning Briefing + Weekly Digest
- Earnings Calendar

→ **เปรียบ:** แทนต้องนั่งเฝ้ากราฟทั้งวัน ให้บอทคอยส่งข้อความหา

- โชว์: กราฟ + Trend Radar + ราคาแนวรับ/แนวต้าน + AI Insight

## 💬 Common Objections & Answers

### Q: "ราคาแพงไป 79 บาท"
**A:** เทียบกับค่ากาแฟ 1 แก้วต่อเดือน + ไม่ต้องเสียเวลานั่งดูกราฟเอง + ถ้าใช้แผนถูกจังหวะเดียวก็คืนทุนแล้วครับ

### Q: "ใช้แอปอื่นฟรีก็ได้ (Tradingview, Investing.com)"
**A:** Tradingview ต้องอ่านกราฟเอง รู้จัก indicator เอง ส่วน Apexify บอกเลยว่าตอนนี้ "น่าสะสม / ระวัง" + Entry/TP/SL ชัดเจนเป็นตัวเลข — ไม่ต้องตีความ

### Q: "AI จะมั่ว/ผิดพลาดไหม"
**A:** มี Track Record (`/track`) ให้ดูได้เลยว่า hit rate เท่าไร 30/90 วัน + ทุก Plan มี SL บอกชัดว่าจุดไหนคือผิดทาง — ไม่ต้องเสี่ยงเอง

### Q: "ใช้กับหุ้นไทยได้ไหม"
**A:** ได้ครับ พิมพ์ `PTT.BK` `AOT.BK` หรือพิมพ์แค่ `PTT` ก็ได้ บอทจะลอง .BK อัตโนมัติ + รองรับหุ้นทั่วโลก US, ไทย, ฮ่องกง, ญี่ปุ่น, ออสเตรเลีย

### Q: "ต่างกัน VIP กับ PRO ยังไง"
**A:**
- **VIP 79฿:** เห็นกราฟ + AI วิเคราะห์ภาพรวม + Watch Next + ข่าว/Briefing
- **PRO 109฿:** ทุกอย่าง VIP + **Plan เทรดเป็นตัวเลข Entry/TP/SL** + กราฟวาด zone + Smart Alerts + Price Alerts

→ "ถ้าอยากให้บอทบอกว่าซื้อตรงไหนเลย → PRO ครับ"

### Q: "ลองก่อนได้ไหม"
**A:** ได้! `/freetrial` ทดลอง PRO 7 วันฟรี ไม่ต้องผูกบัตร ไม่ต้องโอนเงิน หมดแล้ว auto downgrade เป็น free

### Q: "สมัครยังไง"
**A:** กดเมนู "💎 บัญชี / VIP" → เลือกแพ็กเกจ → โอนเงิน → ส่งสลิปในแชท → AI อ่านสลิป upgrade ใน 3 วินาที

### Q: "หมดแล้วต่ออายุยังไง"
**A:** บอทจะส่งเตือน 7/3/1 วันก่อนหมด พร้อมปุ่มต่ออายุทันที

### Q: "ชวนเพื่อนได้ส่วนลดไหม"
**A:** มีระบบ referral! ทุกเพื่อนได้ +3 quota, ครบ 3 คน +10 วัน VIP/PRO และเพื่อนคุณก็ได้ VIP 3 วันฟรีทันทีด้วย

## 🎁 Current Promo Strategy (สำคัญ!)

> **ตอนนี้เน้น "แจก VIP/PRO ฟรี" ไม่ใช่ "ลดราคา"**
> เพราะฐาน user ยังน้อย — ต้องดึงคนเข้ามาใช้ก่อน
> ส่วนลด/โค้ดเก็บไว้ใช้ตอนมีฐานเยอะแล้ว

### 4 ช่องทาง "แจก" ที่ใช้ได้ตอนนี้

**1. 🎁 Free Trial PRO 7 วัน (ทุกคนใหม่)**
- พิมพ์ `/freetrial` → ได้ PRO 7 วันทันที
- ไม่ต้องโอนเงิน ไม่ผูกบัตร
- หลัง 7 วัน → กลับเป็น Free อัตโนมัติ
- ใช้ได้ 1 ครั้งต่อบัญชี

**2. 🤝 Referral (ทุกฝั่งได้)**
- เพื่อนใหม่ → VIP **3 วันฟรี** ทันที
- คุณ (referrer) → +3 quota หรือ +10 วัน (ครบ 3 คน)
- WIN-WIN — แชร์ได้ตลอด

**3. 🔥 Daily Streak**
- ใช้ทุกวันติดต่อกัน 7 วัน → VIP **+1 วันฟรี**
- ทำลายสถิติได้ไม่จำกัดครั้ง

**4. 💎 Promo Code (ใช้ได้แล้ว — แบบ "แจกของฟรี")**

ระบบปัจจุบันรองรับ "แจกวัน VIP/PRO" ผ่านโค้ด:

```
Admin สร้าง:  /createcode APEX2026 7 100 vip
              (โค้ด, จำนวนวัน, max uses, role)

User ใช้:    /redeem APEX2026
              → ได้ VIP +7 วัน ทันที
```

**Use cases ที่ใช้ได้เลย:**
- 🎁 แจกผ่าน influencer ("ใช้โค้ด @username รับ VIP 7 วัน")
- 🎯 Win-back ("คุณห่างหายไปนาน — โค้ด WELCOMEBACK รับ 14 วัน")
- 🎉 Special event (ครบ 1000 user → โค้ด CELEBRATE)
- 👥 B2B / event partner (โค้ดเฉพาะกลุ่ม)

> ⚠️ **ระบบนี้แจกของฟรีอย่างเดียว** — ไม่ใช่ส่วนลด %
> ถ้าจะทำ **"ส่วนลดราคา"** เช่น "30% off" ต้องสร้างระบบเพิ่ม:
> 1. คำนวณราคาลดในขั้นตอนแสดง pricing card
> 2. แก้ตรวจสลิปให้ยอมรับยอดลดลง
> 3. ผูก promo code กับ user ก่อนชำระเงิน + กันใช้ซ้ำ
> → เก็บไว้ทำตอนคนเยอะแล้ว ตอนนี้ใช้แบบ "แจก" ก็พอ
