### 2. Critical bugfix — JS TDZ + SQL cast (`e4fecd1`) ⭐⭐
**2 บั๊กไม่เกี่ยวกันที่ทำให้ admin dashboard ขึ้นเป็นหน้าเปล่า**

**BUG-1: Temporal Dead Zone**
- `const TC` + `const chartOpts` ประกาศที่ line 1635/1648 แต่ใช้ที่ 1539-1551 (`renderWinRateTrend`)
- Hoisting ไม่ช่วย const → throw `ReferenceError: Cannot access TC before initialization`
- Pattern ของ `<script>` ทำให้ทุก IIFE หลังจุดที่ throw หยุด → heatmap, 30-day charts, win rate trend ทั้งหมดขึ้นว่าง
- Fix: ย้าย TC + chartOpts ไปบน renderWinRateTrend (~line 1507)

**BUG-2: String comparison ใน funnel SQL**
- `users.expiry_date` schema เป็น TEXT
- Funnel query เขียน `expiry_date > NOW()` — Postgres ทำ string compare → paying_now/vip_now/pro_now = 0
- Fix: เปลี่ยนเป็น `expiry_date::timestamp > NOW()` ทั้ง active paying + churned-30d query

## 🐛 Lessons learned

1. **JS const TDZ** — ลำดับ declaration ใน `<script>` มีผล. ฟังก์ชันที่ใช้ const ต้องอยู่ "หลัง" constant ประกาศ (ไม่เหมือน function declaration)
2. **Postgres string vs timestamp** — column type TEXT ต้อง cast ทุกครั้ง ไม่งั้น compare เงียบเป็น string
3. **ETF ≠ spot** — gold ETF tracking premium/discount, futures (=F) ใกล้ spot กว่า. ลูกค้าคาด "ราคาทองจริง"
4. **Cross-user metrics จาก shared DB** — ไม่ต้องสร้าง API endpoint ใน webmaster ถ้าทั้งคู่ใช้ Supabase project เดียว (psycopg2 connection ตรง — fail-soft pattern จำเป็น)
