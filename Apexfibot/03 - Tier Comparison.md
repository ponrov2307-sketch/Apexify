## Logic การแบ่ง

### Free (ดึงดูดใหม่)
- ภาพรวมเทคนิคพื้นฐาน
- มี upsell CTA ในรายงาน
- 3 ครั้ง/วัน รีเซ็ตเที่ยงคืน
- เมื่อ quota หมด → inline button ให้สมัครทันที
- เห็น `/track` ได้ → proof ว่าระบบแม่น

### VIP (เข้าใจภาพรวม)
- รู้ว่าหุ้นนี้น่าสน/ไม่น่าสน
- มี AI วิเคราะห์ 3 timeframes
- ต้องดูอะไรต่อ
- ไม่มี Plan ตัวเลข → push ไป PRO

### PRO (วางแผนเทรดได้เลย)
- ตัวเลขชัด: Entry, TP1, TP2, SL พร้อม %
- กราฟ annotated → ดูในภาพเดียวจบ
- Management rules: เงื่อนไขยืนยัน + ยกเลิก
- Smart Alerts ตามไปด้วย

## Default report length
- Free: ~10-15 บรรทัด
- VIP: ~25-30 บรรทัด
- PRO: ~40-50 บรรทัด (เพราะมี Plan + Conditions)
