# 💬 DM & Closing Scripts

> Script ครบทั้ง flow — เปิด, สร้างความสนใจ, สาธิต, ปิดการขาย, follow-up
> ปรับตาม persona ลูกค้าได้

---

## 📞 Flow Overview (5 ขั้นตอน)

```
1. Greeting (เปิด - สร้างความเป็นกันเอง)
   ↓
2. Discovery (ถามเพื่อเข้าใจปัญหาเขา)
   ↓
3. Pitch (เสนอ Apexify เป็นทางออก)
   ↓
4. Demo (โชว์ของจริง)
   ↓
5. Close (ปิด — Free Trial หรือ Subscribe)
```

```

```

## 2️⃣ Discovery Questions

### ใช้คำถามเหล่านี้เพื่อเข้าใจ pain point

**สำหรับมือใหม่:**
- "ลงทุนหุ้นมานานยังครับ?"
- "ส่วนใหญ่ดูหุ้นจากไหนครับ? ฟัง guru / อ่านข่าว / กราฟเอง?"
- "เจอปัญหาอะไรบ่อยที่สุด?"

**สำหรับ active trader:**
- "ใช้แอปไหนเป็นหลักครับ?"
- "ใช้เวลาวันละกี่ชม. ในการดูหุ้น?"
- "ปกติตั้ง SL ไหมครับ?"

**สำหรับมนุษย์เงินเดือน:**
- "งานยุ่งไหมครับ? มีเวลาดูหุ้นแค่ไหน?"
- "อยากให้ใครช่วยเฝ้าให้ไหม?"

**สำหรับคนกลัวเสียเงิน:**
- "เคยเสียเงินจากการลงทุนไหมครับ?"
- "เพราะอะไรถึงกลัว?"
- "ถ้ามีเครื่องมือบอกชัดว่า ผิดทาง ตรงไหน จะช่วยไหม?"

### Universal Question (ใช้ได้ทุก persona)
```
ถ้ามีบอท AI ที่:
- พิมพ์ชื่อหุ้น 10 วิ ได้รายงานครบ
- บอก Entry/TP/SL ตัวเลข
- แจ้งเตือนอัตโนมัติ

จะลองดูไหมครับ ฟรี 7 วัน?
```

## 3️⃣ Pitch Scripts (Match กับ Persona)

### P-1: มือใหม่ (อายุ 22-30)
```
ผมเข้าใจครับ ลงทุนใหม่ๆ มันสับสน
ดูกราฟไม่เป็น ไม่รู้จะเริ่มยังไง

ลองนึกภาพแบบนี้นะครับ:
"มีนักวิเคราะห์ส่วนตัวคอยตอบคำถามคุณ 24 ชม.
อยากรู้หุ้นอะไรพิมพ์ — เขาอ่านกราฟให้
อ่านข่าวให้ บอกว่าควรซื้อตรงไหน"

นั่นแหละครับ Apexify
แต่ราคา 79 บาท/เดือน — ไม่ใช่ 5,000
ลองฟรี 7 วันก่อนได้ ไม่ต้องผูกบัตรครับ
```

### P-2: Active Trader (อายุ 25-40)
```
สำหรับเทรดเดอร์ที่ active แบบคุณ
PRO น่าจะตอบโจทย์ที่สุดครับ

จุดเด่น:
🎯 Plan สำเร็จรูป — Entry zone / TP1 / TP2 / SL พร้อม %
📊 R:R warning — บอกถ้า setup ไม่คุ้มเสี่ยง
🔔 Smart Alerts — RSI/MACD/Volume spike ทุก 5 นาที
⚖️ /compare 2-3 หุ้น — AI ตัดสินตัวไหนดีกว่า

ใช้แทน workflow ดู Tradingview + indicator เอง
ประหยัดเวลาวันละ 1-2 ชม. ครับ

ลอง /freetrial 7 วัน ดูจริงไหม
```

### P-3: มนุษย์เงินเดือน (อายุ 28-45)

```
งานยุ่งไม่มีเวลานั่งดูกราฟ — ผมเข้าใจครับ

VIP 79฿/เดือน หรือ PRO 109฿
ลอง 7 วันฟรี ไม่ผูกบัตรครับ
```

### P-4: ผู้บริหาร (อายุ 40+)
```

ค่าใช้จ่าย 79 บาท/เดือน — เท่ากาแฟแก้วเดียว
```

## 5️⃣ Closing Scripts

### C-1: Soft close (ลองก่อน)
```
ผมไม่ get hard sell นะครับ

ผมแค่อยากให้คุณลองดูจริงๆ
ฟรี 7 วัน ไม่ผูกบัตร — ไม่มีอะไรให้เสีย

ถ้าหลัง 7 วันรู้สึกว่าไม่คุ้ม ก็ปล่อยหมดอายุได้เลย
ระบบจะ downgrade เป็น Free อัตโนมัติ

จะลองดูไหมครับ?
```

### C-2: Direct close (พร้อมจ่าย)
```
ดูแล้วน่าจะตอบโจทย์ครับ
จะสมัครเลยไหม?

VIP 79฿/เดือน — ภาพรวมครบ
PRO 109฿/เดือน — Plan เทรดเต็ม

วิธี:
1. กดเมนู 💎 บัญชี / VIP ในบอท
2. เลือกแพ็กเกจ
3. โอน → ถ่ายสลิปส่งในแชท
4. AI อ่านสลิป → upgrade ใน 3 วินาที

จะเริ่มเลยไหม?
```

### C-3: Reduce friction close
```
[ถ้าเขาลังเล]

เข้าใจครับ — งั้นเริ่มจากเล็กๆ ก่อน

ลอง /freetrial ก่อน 7 วัน
ดูว่าใช้แล้วชอบไหม
ถ้าไม่ชอบก็เลิกได้
ไม่ต้องตัดสินใจตอนนี้

แต่ถ้าใช้แล้วชอบ
ค่อยกลับมาคุยเรื่องสมัครต่อ ตกลงไหมครับ?
```

### C-4: Urgency close (ใช้เมื่อมี promo จริง)
```
ตอนนี้บังเอิญมีโค้ดพิเศษอยู่
{CODE} = รับ {N} วันฟรี

ใช้ได้ {X} คนเท่านั้น
หมดเขต {date}

อยากใช้ไหมครับ?
จะส่งวิธีให้ทันที
```

### C-5: Risk reversal close
```
ผมรู้ว่าคุณยังไม่มั่นใจ — เป็นเรื่องปกติ

แต่ลองคิดดูนะครับ:
- ฟรี 7 วัน — ไม่เสียเงิน
- ไม่ผูกบัตร — ไม่ต้องกลัวถูกตัด
- ดู /track พิสูจน์ stats — ไม่ใช่อ้างลอยๆ

ถ้าใช้แล้วไม่ชอบ คุณเสียอะไรไปครับ?
ไม่มีเลยใช่ไหม

งั้นลองเลยครับ แค่พิมพ์ /freetrial
```

### C-6: Comparison close
```
[ถ้าเปรียบกับ Tradingview/แอปฟรี]

จริงครับ Tradingview ฟรี
แต่คุณต้อง:
- เรียน indicator เอง
- ดูกราฟเอง
- ตีความเอง
- เปิดทุกวันเอง

Apexify 79฿/เดือน:
- AI ทำให้หมด
- บอก Entry/TP/SL
- alert ส่งเอง

79 บาท/เดือน = 2.6 บาท/วัน
น้อยกว่าค่ากาแฟเย็น 1 แก้ว
แลกกับเวลา 2 ชม./วัน

คุ้มไหมครับ?
```

### C-7: Anchoring close
```
นักวิเคราะห์มืออาชีพที่ปรึกษา
ค่าตัวเดือนละ 5,000-15,000 บาท

แอป premium ทั่วไป (Bloomberg, Refinitiv)
$2,500/ปี = 7,500 บาท/เดือน

Apexify:
```

## 7️⃣ Special Situations

### S-1: ลูกค้าเพิ่งเสียเงินตลาด
```
ผมขอโทษด้วยครับเรื่องที่เกิดขึ้น
รู้สึกท้อมั้ยครับ?

[ฟัง — empathize 1-2 ประโยค]

ผมไม่ได้บอกว่า Apexify จะทำให้คุณรวย
แต่ผมเชื่อว่ามันช่วยให้คุณ:
✅ มี SL ทุก Plan — ไม่ปล่อยขาดทุนใหญ่
✅ Track Record โปร่งใส — รู้ว่าอะไรเวิร์คจริง
✅ ระบบตัดสินใจ — ไม่เทรดด้วยอารมณ์

ลองดูฟรี 7 วันก่อนได้ครับ
ไม่มีอะไรเสี่ยงครับ ลองดูเฉยๆ
```

### S-2: ลูกค้าทดลอง 2 ครั้งแล้ว
```
ขอบคุณที่ให้โอกาสบอทอีกครั้งครับ 🙏

มีอะไรที่ผม/ทีม Apexify ทำได้ดีกว่านี้ไหมครับ?
ส่วนไหนของบอทที่ยังไม่ตอบโจทย์?

ผมอยากเข้าใจจริงๆ — เพื่อปรับปรุง
และถ้าคุณยังอยากลองรอบ 3
ผม set free trial พิเศษ 14 วันให้ได้ครับ
```

### S-3: ลูกค้าถามฟีเจอร์ที่ยังไม่มี
```
ขอบคุณสำหรับ feedback ครับ
ฟีเจอร์ {feature} ยังไม่มีในเวอร์ชันปัจจุบัน

แต่:
✅ ผมเขียนเก็บไว้ใน roadmap แล้ว
✅ ถ้ามี user ขอเรื่องเดียวกันเยอะ จะ prioritize

ระหว่างนี้ ฟีเจอร์ที่คล้ายๆ ที่ใช้ได้:
```

## 8️⃣ Texting Etiquette (สำหรับ DM)

### Do
- ✅ ตอบเร็ว (ภายใน 1-2 ชม. ในเวลาทำงาน)
- ✅ ใช้ emoji แต่พอประมาณ
- ✅ ภาษากันเอง — ไม่ formal เกิน
- ✅ ขึ้นบรรทัดใหม่บ่อยๆ — อ่านง่าย
- ✅ ใช้ชื่อลูกค้าเสมอ
- ✅ ขอบคุณ + จบสุภาพ

### Don't
- ❌ ตอบยาวเป็นเรียง 10 ย่อหน้า
- ❌ พิมพ์ภาษาวิบัติ (น่ารัก น่ารักก, ค่ะะะ)
- ❌ Hard sell หลายรอบ
- ❌ Spam emoji 20 ตัว 1 บรรทัด
- ❌ ไม่ทักไป 3 วัน — แล้วอยู่ดีๆ ทักขายแบบมารยาทไม่ดี

### เวลาที่ควร DM
- 🌅 9:00-12:00 (ก่อนเที่ยง — engagement สูง)
- 🍽 13:00-15:00 (พักกลางวัน)
- 🌆 18:00-21:00 (เลิกงาน)
- ❌ 22:00-08:00 (กลางคืน — รอเช้า)
- ❌ วันหยุดยาว เช่น สงกรานต์ ปีใหม่

## 🔟 Advanced Closing Tactics

### Assumptive Close
```
"งั้น VIP หรือ PRO ดีครับ?"
(สมมติว่าตัดสินใจซื้อแล้ว — เลือกแค่ tier)
```

### Alternative Close
```
"จ่ายรายเดือน 79 หรือรายปี 790 ดีครับ?
รายปีประหยัด 158 บาท นะครับ"
(ให้เลือก 2 option ที่ทั้งคู่ = ขาย)
```

### Summary Close
```
"สรุปสิ่งที่คุณจะได้:
✅ AI วิเคราะห์ไม่จำกัด
✅ Plan Entry/TP/SL ทุกหุ้น
✅ Smart Alerts 24/7
✅ /compare /ask /track ครบ
✅ Morning Briefing + News

ทั้งหมดนี้ 109฿ — น้อยกว่าค่ากาแฟ 1 แก้ว/วัน
จะเริ่มไหมครับ?"
```

### Trial Close
```
"ถ้าผมแก้ปัญหา {ปัญหาที่เขายกมา} ได้
คุณพร้อมสมัครเลยไหมครับ?"
```

### Question Close
```
"มีอะไรที่ยังไม่ชัดเจน หรือยังกังวลอยู่ไหมครับ?
ผมตอบให้หมด แล้วเราค่อยตัดสินใจ"
```
